🧾 Insurance Data Preprocessing for ML
📌 Overview

This project prepares an insurance dataset for machine learning by performing EDA, data cleaning, and feature engineering.

📂 Dataset

Includes:

Age, Gender, BMI
Children, Smoking status, Region
💰 Charges (Target)
🔍 What’s Done
🧹 Data Cleaning
Removed duplicates
Handled missing values
Fixed data types
📊 EDA
Feature distributions
Correlation analysis
Outlier detection
⚙️ Feature Engineering
Encoding (categorical → numeric)
Feature scaling
Outlier treatment
🤖 Output
Clean, structured dataset
Ready for ML models (Regression, Tree-based, etc.)
🛠️ Tech Stack

Python • Pandas • NumPy • Seaborn • Scikit-learn

🚀 Quick Start
pip install -r requirements.txt
jupyter notebook
🎯 Goal

Transform raw data → ML-ready dataset for accurate predictions.
